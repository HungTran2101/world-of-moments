# Product roadmap

The public map, thought submission, private history and moderation workspace form the current release. The phases below describe feature priorities. Some later-phase features already support the core experience.

| Phase | Available today | Planned work |
| --- | --- | --- |
| 1. Map and writing | Interactive 2D map, place-based thoughts, weather context, client accounts and searchable private history. | Core flow implemented. |
| 2. Motion and interaction | Marker transitions, thought dialog, submission animation and responsive controls. | Continue refining motion and accessibility as interactions evolve. |
| 3. Realtime arrivals | The map refreshes as visitors explore and after they submit a thought. | Introduce quiet marker arrivals for thoughts submitted by other visitors. |
| 4. Future messages | The feature is disabled. | Let people send a message to their future self and open it when its condition is met. The feature requires client-account authentication. |
| 5. Globe exploration | Zooming out already reveals a satellite globe with a star field. | Explore richer globe interactions while keeping the 2D map primary. |
| 6. Moderation and stability | The CMS supports review, publication controls, bulk actions and account administration. | Add reporting and strengthen spam protection. |
| 7. Scaling | Viewport queries, marker clustering, on-demand thought details and compressed public reads. | Evaluate spatial query improvements and weather caching as usage grows. |

See [product behavior](project.md) for the visitor experience and [architecture](architecture.md) for the implementation.
